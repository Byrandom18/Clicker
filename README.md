# Clicker

Кликер-бой для Яндекс Игр на Unity: кликаешь по врагам, покупаешь улучшения, проходишь фазы и этапы.

## Стек

- Unity `6000.0.79f1`
- C#, Input System, TextMesh Pro
- Плагин **Plugin Your Games** (YG) для Яндекс Игр
- WebGL-сборка в корне: `build_YandexGames_Build.zip`
- Материалы магазина: `Store/Yandex`

## Что есть в игре

- Бой по слотам врагов и смена фаз
- Магазин улучшений и HUD
- Автоулучшения и атака за рекламу
- Реплики, попапы урона, VFX и звук
- Сохранение прогресса

Игровая логика собрана вокруг `Assets/Scripts/ClickerGame.cs`. Данные лежат в `Assets/Resources/Data`, префабы — в `Assets/Prefabs`.

## Как открыть

1. Поставь Unity `6000.0.79f1`.
2. Открой папку репозитория как проект.
3. Запусти сцену с `ClickerGame` (обычно `GameRoot`).

Для публикации на Яндекс Играх используй WebGL-шаблоны в `Assets/WebGLTemplates` и готовую сборку в корне.
